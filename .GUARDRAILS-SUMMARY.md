## 🎯 How Claude Should Use This

### When Adding a New Feature

1. **Identify type:** Is it a tool? Command? Message? Test?
2. **Load skill:** `cat .claude/skills/{skill-name}.md`
3. **Follow steps:** 1 through 7 (or however many)
4. **Use examples:** Copy code patterns from skill
5. **Check checklist:** Complete all items
6. **Validate:** `./claude/hooks/run-all-checks.sh`

### Before Every Commit

```bash
./.claude/hooks/run-all-checks.sh  # Validates all constraints
pnpm run check-types && pnpm run lint
pnpm test-unit && pnpm test-mcp    # If changed code/tests
git push
```

## 🎓 Key Principles

1. **Two-process architecture is sacred** — Server is pure Node.js (no `vscode`).
2. **Smart routing** — Every tool carries `projectPath` arg, resolved via `ClientRegistry`.
3. **Protocol symmetry** — Every message type has handlers in both `McpServer.ts` AND `ServerConnection.ts`.
4. **Bilingual always** — All user-facing text in both EN + ZH l10n files.
5. **Tests first** — New tools/messages require tests before commit.
6. **Hooks validate** — Always run `run-all-checks.sh` before pushing.
